# Item Price Prediction

A Python machine learning project for predicting retail item prices using regression models.
Built as a team competition project at Ain Shams University.

## My Contribution
- Implemented the LightGBM model (MAE: 0.376) with early stopping and native categorical feature handling
- Built the full EDA and visualization suite (target distribution, correlation heatmap, outlet-type analysis, MRP vs price scatter)

## Technologies
Python, scikit-learn, LightGBM, XGBoost, CatBoost, pandas, matplotlib, seaborn

## Models
- Linear Regression — MAE: 0.421
- Ridge Regression — MAE: 0.426
- XGBoost — MAE: 0.397
- LightGBM — MAE: 0.376
- CatBoost — MAE: 0.373 (best)
